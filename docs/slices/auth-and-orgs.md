## How to read this doc

Each row maps a single requirement to its **implementation site**
(the production code that satisfies it), its **verification site**
(what the test asserts), and the **test file** that runs in CI.
Rows are honest — if an AC is delegated, partially covered, or
shipped behind a deferred backstop, the row says so out loud rather
than inventing coverage.
