datum/room

Design system

An ink-on-paper system for a secure data room handling legally sensitive material. It is built to feel calm and auditable, never busy — and to make one promise visible everywhere: a single reserved colour means “this came from the AI.”

Surfaces warm neutral Type Source Serif 4 · IBM Plex Sans · IBM Plex Mono AI contract Signal Indigo
01Principles
Ink on paper
Warm off-whites and warm ink. No pure black or white, no gradients, no glow. The room should read like a well-kept ledger, not a dashboard.
One reserved AI colour
A single chromatic hue is reserved exclusively for AI output — citations, sense-checks, suggestions, AI audit entries. Chrome and status never use it, so its presence always means one thing.
Status is its own language
Ok / warn / error / pending have a muted, desaturated palette that stays clear of the AI hue — so an amber-style “warn” never gets mistaken for an AI signal.
Calm density
Hairline rules, two subtle shadow layers, tight radii (3–8px). Tabular numerals on every count, timestamp and identifier.
