# /briefs — one-pagers per initiative

Every idea, automation, content series, or playbook starts here as a
one-page brief before it becomes a spec.

- **Template:** `_TEMPLATE.md`
- **Naming:** `YYYY-MM-DD-<slug>.md` or just `<slug>.md` if always referenced
  by slug. Keep slugs kebab-case.
- **Promotion path:** brief → spec (`/specs/<slug>/`) once the idea is
  validated enough to design.

## Categories

- `/briefs/saas/` — product ideas
- `/briefs/internal/` — automations for Bradley's fintech team
- `/briefs/personal/` — Bradley's own workflow automations
- `/briefs/content/` — LinkedIn / X / newsletter / video series
- `/briefs/playbooks/` — reusable "how to handle X" knowledge from meetings

(Subfolders are created lazily — don't create empty ones.)
