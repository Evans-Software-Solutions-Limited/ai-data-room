# Migrations

Generated by `drizzle-kit generate`, checked in, applied by `drizzle-kit migrate`.

Hand-written SQL is allowed for Postgres-specific DDL that Drizzle's generator doesn't emit cleanly:

- `pgvector` extension creation (slice 6 T-001).
- Partial unique indexes (single-owner-per-org, email uniqueness excluding `lifecycle_state='deleted'`).
- Append-only audit triggers (SOC 2 entry — post-MVP).

Rollback scripts live alongside each migration following Drizzle conventions.
